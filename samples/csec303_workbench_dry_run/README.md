# CSEC303 Workbench Dry Run

This is a public, low-stakes sample for testing the generic Custos Jupyter Workbench.

- `CSEC303_Workbench_Dry_Run.zip` can be uploaded in **Instructor View → assessment → Jupyter Workbench**.
- `questions.csv` can be imported into the same assessment.
- `seed_csec303_workbench_test.py` at the project root creates the complete dry run automatically on a local database.

The exercise uses generated data only and intentionally has a public answer key.
