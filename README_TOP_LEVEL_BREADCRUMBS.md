# Custos top-level breadcrumb removal patch

Removes breadcrumbs from the public/top-level entry pages only:

- Home (`portal.html`)
- Student View (`student_login.html`)
- Instructor View (`admin_login.html`)
- IDE Coming Soon (`ide_coming_soon.html`)
- Future student IDE sign-in (`ide_login.html`)

Breadcrumbs remain enabled on deeper pages such as Workspace, Dashboard, Monitor, Item Analysis, Question Banks, Session Review, Instructions, and IDE subpages.
