# CSEC 303 Midterm Laboratory — Student Case Kit

1. Extract this ZIP into its own folder.
2. Open `CSEC303_Midterm_PHANTOM303.ipynb` in Jupyter Notebook or JupyterLab.
3. Keep the notebook and Custos open side by side. Switching between them is allowed for this assessment.
4. Run the notebook from top to bottom and use the generated measurements to answer Custos Q1–Q20.
5. Do not overwrite the source evidence files. If you want to save experimental outputs, create new filenames.

If your Python environment is missing packages, install the lab dependencies with:

```bash
pip install -r requirements_lab.txt
```

The medical-image materials are provided for image-processing education only. Do not treat the exercise as a clinical diagnosis task.
